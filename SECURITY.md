# Security policy

## Reporting a vulnerability

Please email **support@crawlcove.com** with "Security: Crawl Cove Connector" in the subject. Do not open a public issue.

Include the plugin version, your WordPress and SEO plugin versions, and the steps that show the problem. A request and response pair (with passwords removed) is the most useful thing you can send.

We will confirm we have your report, work on a fix, and credit you in the changelog unless you would rather not be named.

## Supported versions

Only the latest release gets security fixes. Download it from the [latest GitHub release](https://github.com/CrawlCove/wordpress-seo-connector/releases/latest).

## How the plugin is tested

[SECURITY-NOTES.md](SECURITY-NOTES.md) records the security passes run against a real WordPress install: authentication on every route, the capability matrix, input fuzzing and the fixes that came out of them.
